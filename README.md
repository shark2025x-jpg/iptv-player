# IPTV Плеер (телефон + Android TV)

Один APK для телефона и телевизора. Установка в 1 клик.

## Как получить APK (5 минут, без Android Studio)

1. Зарегистрируйтесь на github.com (бесплатно) и создайте **новый репозиторий** (например `iptv-player`).
2. Нажмите **Add file → Upload files**, перетащите **всё содержимое** этой папки
   (включая скрытую папку `.github`) и нажмите **Commit changes**.
3. Откройте вкладку **Actions** → дождитесь зелёной галочки (≈5–8 минут).
   Если сборка не стартовала — выберите workflow **Build APK** → **Run workflow**.
4. Готовый файл `IPTV-Player.apk`:
   - справа на главной странице репозитория в разделе **Releases → IPTV Player (latest)**, или
   - в Actions → последний запуск → **Artifacts → IPTV-Player-apk**.
5. Скачайте APK на телефон и откройте его (разрешите установку из этого источника).

## Установка на телевизор
- Скопируйте APK на флешку и установите через файловый менеджер ТВ, **или**
- установите на ТВ приложение **Downloader** и введите прямую ссылку на APK из Releases
  (правой кнопкой на файле → «Копировать адрес ссылки»).

## Возможности
- Несколько плейлистов M3U: по ссылке или из файла, свои названия, переименование, удаление,
  быстрое переключение (меню в правом верхнем углу).
- Телепрограмма (EPG, XMLTV, в т.ч. .gz) — из тега `url-tvg` плейлиста или своя ссылка для каждого плейлиста.
- Архив: прошедшие передачи можно смотреть, если у канала в плейлисте есть `catchup`/`catchup-days`
  (режимы append / shift / default / flussonic).
- История просмотров (каналы и передачи из архива), повторный запуск одним нажатием.
- Избранное: добавить/удалить ★, работает независимо от выбранного плейлиста.
- Поиск по названию канала, группе и текущей передаче; фильтр по группам.
- Управление пультом: ↑/↓ или CH+/CH− — переключение каналов, OK — панель, MENU/INFO — программа,
  ←/→ — перемотка в архиве.
